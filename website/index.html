Getting started

Your terminal. Your bridge. Your API key.

The same app serves the product website and the bridge dashboard. In this temporary local preview, the bridge runs on this computer and has one API-key setting. The EA places trades only through the user's own MT5 terminal; it does not send broker login details to the website.

01 / DOWNLOAD

Get the MT5 Expert Advisor

Download the EA source and compiled Expert Advisor, then install them in your MT5 Experts folder.

02 / CONNECT

Use your own MT5 account

Sign in to your broker in your own MT5 terminal and attach the EA to an M5 chart. The bridge never receives your broker password.

03 / CONFIGURE

Configure the local bridge

Open the bridge dashboard and enter your Anthropic API key. The temporary preview supports this local bridge only.

Please read before trading

AI signals involve real risk.

This software is an experimental tool, not financial advice. AI predictions can be wrong, trades can lose money, API use may incur charges, and broker execution is not guaranteed. Test carefully on a demo account before considering live use.

Local preview: The website and bridge dashboard are served by the same app at 127.0.0.1. This temporary version is reachable only from this computer; other people cannot connect until you deploy a properly secured public service. The current bridge has one API-key setting and is not a multi-user hosted service. Never expose the local bridge directly to the internet.
Exit mapping: This EA build intentionally maps Claude's SL distance to the MT5 take-profit and Claude's TP distance to the MT5 stop-loss, as requested. This reverses normal exit placement and can create poor risk/reward; verify the mapped levels in MT5 and test on demo first.
