01 / MT5 SETUP

Allow the hosted URL

In MT5, open Tools → Options → Expert Advisors, enable WebRequest, and add https://remzaitrading.vercel.app to the allowed URLs.

02 / EA INPUTS

Use your own API key

Attach the EA to an M5 chart. In its Inputs, keep hosted service enabled, paste your Anthropic API key into InpAnthropicApiKey, and set your own lot size. Do not share or publish your key.

03 / YOUR ACCOUNT

Sign in only in MT5

Log in to your broker account in your own MT5 terminal. This website never asks for or receives your broker password, account login, or trading credentials. Orders execute locally in your MT5.

04 / USAGE

Anthropic bills your key

Claude usage is charged by Anthropic to the owner of the API key. The public dashboard does not save per-user settings or display individual account, signal, or trade status.

Important: The hosted API relays market-analysis prompts to Anthropic. It does not execute trades, receive broker credentials, or store API keys or per-user trading status. Keep your key private, use MT5 demo mode first, and verify all orders and SL/TP levels yourself. Signals are experimental and do not guarantee profit.
