01 / SET UP MT5

Allow the hosted URL

In MT5, open Tools → Options → Expert Advisors, enable WebRequest, and add https://remzaitrading.vercel.app to the allowed URLs.

02 / EA INPUTS

Use hosted settings

Attach the updated EA to an M5 chart, keep InpUseHostedService enabled, and use the same Wi-Fi/internet connection where you saved settings. The EA refreshes the configured lot size and model from the bridge every five minutes and before each signal.

03 / YOUR BROKER

Sign in only in MT5

Log in to your broker account in your own MT5 terminal. This website never asks for or receives your broker password, account login, or trading credentials. Orders execute locally in your MT5.

04 / USAGE

Anthropic bills your key

Claude usage is charged by Anthropic to the owner of the API key. The dashboard does not receive your MT5 account number, report your positions, or execute trades.

IP binding: The first public IP that saves an API key claims it. That key cannot be used from another public IP. A Wi-Fi network's public IP is not its private router address; devices on one Wi-Fi usually share the same public IP and settings slot. Anyone on that network can use the configured bridge and may incur Anthropic charges. This is network-level isolation, not a separate user account. If you move networks, create a different Anthropic key; settings expire after 90 days without a save. Your key is encrypted at rest and decrypted only to call Anthropic. Keep it private and revoke it at Anthropic if it is exposed.
Risk: The hosted bridge returns analysis signals only. Trade checks, risk limits, SL/TP, and all order execution stay in your MT5. Test on a demo account first; signals can be wrong and trading can lose money.
